# 🚀 Daystep Telegram Bot

Телеграм-бот для ежедневных микро-челленджей и привычек. Каждый день бот отправляет пользователям случайный квест (спорт, кулинария, осознанность, книги, уют), отслеживает серию дней (стрик 🔥) и напоминает о выполнении вечером.

---

## 🛠 Возможности

- 🌅 **Ежедневная утренняя рассылка в 09:00** с новым случайным заданием.
- 🎯 **Моментальный первый квест** сразу после `/start`, чтобы пользователь включился без задержек.
- 🔄 **Возможность 1 раз в день заменить квест**, если выпало что-то совсем неподходящее.
- ✅ **Быстрое подтверждение** в один клик кнопкой «Выполнил!».
- 🔥 **Система стриков и рангов** (отслеживание текущей и рекордной серии дней без пропусков).
- ⏰ **Вечернее напоминание в 20:00** для тех, кто ещё не успел закрыть квест дня.
- 🚫 **Умная ротация:** не повторяет недавние квесты (за последние 7 дней).

---

## 🚀 Быстрый запуск

### 1. Настройка токена
Создайте файл `.env` на основе [.env.example](file:///d:/Тг%20боты/Daystep%20gravity/.env.example):
```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
TIMEZONE=Europe/Moscow
DEFAULT_QUEST_HOUR=9
REMINDER_HOUR=20
```

### 2. Запуск бота
Виртуальное окружение `venv` уже создано и все зависимости установлены:
```powershell
.\venv\Scripts\python.exe main.py
```
